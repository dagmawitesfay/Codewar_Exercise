## Codewars Practice Repository

A collection of JavaScript Codewars kata solutions, organized into individual challenge folders. Each folder contains a standalone implementation and a small example call so the solution can be run directly with Node.js.

## Overview

This repository is focused on practicing core JavaScript concepts such as:

- Arrays and array methods
- Loops and conditionals
- String manipulation
- Math and number validation
- Sorting and filtering
- Problem-solving patterns used in Codewars challenges

## How to run a solution

From the repository root, navigate into any challenge folder and run the file with Node.js:

cd 8kyu-mixed-Array-Sum
node main.js


**Notes**
- These are practice solutions written in plain JavaScript.
- The focus is on understanding and solving the challenge rather than building a full application.
- Each folder is meant to be self-contained and easy to inspect individually.
